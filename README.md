🏋️ FitLog — Workout Library

A dark, no-nonsense gym companion. Pick a lift, lock it into today's plan, and watch the week's work add up.


📖 About the Project

FitLog is a responsive workout library web app. Users can browse 12 lifts covering every major muscle group, open a workout to see its specs and instructions, add it to Today's Plan or Saved, and track total exercises, minutes and calories on the My  Plan page.


# Technologies Used
1. Next.js 16	
2. App Router (Next.js)	
3. React	
4. Tailwind CSS	
5. lucide-react	



✨ Key Features
1. Workout Library — all workouts from the API shown as cards in a responsive 3-column grid, with image, muscle tags, equipment and duration / calories / rating stats.
2. Sort & Search — sort the library by Duration, Calories or Rating, and search by workout name or muscle group.
3. Workout Details Page — two-column layout with a large image, key specs table and step-by-step instructions.
4. Today's Plan & Saved — "Add to today's plan" and "Save for later" buttons update the navbar badge counters instantly and show toast notifications.
5. My Plan Dashboard — live Exercises / Minutes / Calories metrics, tabs for Today's Plan and Saved, Mark as Done and Remove actions, and a friendly empty state.
